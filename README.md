# 💼 Ingrid CRM

Sistema de gerenciamento de clientes e oportunidades desenvolvido como projeto de portfólio, com foco na aplicação prática de conceitos de desenvolvimento Full Stack.

O **Ingrid CRM** tem como objetivo centralizar informações de clientes, acompanhar oportunidades comerciais e facilitar a visualização do processo de atendimento e negociação.

---

## 🚀 Funcionalidades

O projeto está em desenvolvimento e contará com:

- 🔐 Cadastro e autenticação de usuários
- 👥 Cadastro e gerenciamento de clientes
- 📋 Listagem de clientes
- 🔎 Pesquisa e filtros
- ✏️ Edição de informações
- 🗑️ Exclusão de registros
- 💼 Gerenciamento de oportunidades
- 📌 Status das negociações
- 📊 Dashboard com indicadores
- 📈 Métricas comerciais
- 🔒 Rotas protegidas
- 📱 Interface responsiva
